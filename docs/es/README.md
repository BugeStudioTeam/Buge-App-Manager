**Buge App Manager** es una potente utilidad para Android diseñada para la gestión avanzada de aplicaciones y permisos. Creada con **Material Design 3 Expressive**, ofrece una interfaz moderna e intuitiva para un control detallado de tu dispositivo.

## Características

### Capacidades principales

| Característica                        | Descripción                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| **Integración con Shizuku**           | Funciona con la autorización de Shizuku para un control avanzado sin root        |
| **Integración con Dhizuku**           | Funciona con la autorización de administrador de dispositivo de Dhizuku sin root |
| **Integración con ROOT**              | Funciona con la autorización de ROOT para un control avanzado                    |
| **Gestión de aplicaciones**           | Explora y gestiona fácilmente aplicaciones de usuario y del sistema              |
| **Interfaz Material Design 3 Expressive** | Interfaz limpia con el tema del sistema, siguiendo las últimas guías de diseño de Android |

### Gestor de aplicaciones

- Gestiona cualquier aplicación, **incluidas las del sistema**

- Admite operaciones avanzadas como **desinstalar**, **deshabilitar**, **forzar detención**, etc.

- Permite **restaurar aplicaciones del sistema desinstaladas**

### Gestor de permisos

- Consulta y modifica los permisos de las aplicaciones por **categoría**
- Categorías compatibles: micrófono, cámara, acceso a ubicación, notificaciones, teléfono y contactos, almacenamiento y otras
- Filtra los permisos por estado **concedido** o **denegado**
- Operaciones de permisos por lotes para varias aplicaciones

### Lanzador de actividades

- Explora y **lanza** cualquier actividad
- Consulta actividades no exportadas

### Privacidad y seguridad

- Identifica rápidamente qué aplicaciones tienen acceso a permisos sensibles
- Optimiza la seguridad de tu dispositivo con una visión clara de los permisos

## Requisitos

| Requisito | Versión mínima                        |
| --------- | ------------------------------------- |
| Android   | 8.0 (API 26) o superior               |
| Shizuku   | Instalado y autorizado                |
| Dhizuku   | Instalado y autorizado                |
| ROOT      | Dispositivo rooteado y autorizado     |

Elige entre la autorización de **Shizuku**, **Dhizuku** o **ROOT**.

> **Nota**: se requiere [Shizuku](https://shizuku.rikka.app/) o [Dhizuku](https://github.com/iamr0s/Dhizuku) para las funciones avanzadas de gestión de permisos.
