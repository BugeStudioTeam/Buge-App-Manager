**Buge App Manager** — это мощное служебное приложение для Android, предназначенное для расширенного управления приложениями и разрешениями. Созданное с использованием **Material Design 3 Expressive**, оно предлагает современный и интуитивно понятный интерфейс для детального контроля над вашим устройством.

## ✨ Возможности

### 🚀 Основные возможности

| Функция                              | Описание                                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| **Интеграция с Shizuku**             | Работает с авторизацией Shizuku для расширенного управления без необходимости root |
| **Управление приложениями**          | Просматривайте и управляйте как пользовательскими, так и системными приложениями с лёгкостью |
| **Интерфейс Material Design 3 Expressive** | Чистый, системно-тематический интерфейс, следующий последним руководствам по дизайну Android |

### 📱 Менеджер приложений

- Управляйте любыми приложениями, **включая системные**

- Поддерживает расширенные операции, такие как **удаление**, **отключение**, **принудительная остановка** и др.

- Позволяет **восстанавливать удалённые системные приложения**

### 🔐 Менеджер разрешений

- Просматривайте и изменяйте разрешения приложений по категориям
- Поддерживаемые категории: Микрофон, Камера, Доступ к местоположению, Уведомления, Телефон и Контакты, Хранилище и Другие
- Фильтруйте разрешения по статусу **предоставлено** или **отказано**
- Пакетные операции с разрешениями для нескольких приложений

### 🧩 Запуск Activity

- Просматривайте и **запускайте** любые Activity
- Отображайте неэкспортированные Activity

### 🛡️ Конфиденциальность и безопасность

- Быстро определяйте, какие приложения имеют доступ к чувствительным разрешениям
- Оптимизируйте уровень безопасности вашего устройства с помощью чёткой информации о разрешениях

## 📋 Требования

| Требование  | Минимальная версия          |
| ----------- | --------------------------- |
| Android OS  | 8.0 (API 26) или выше       |
| Shizuku     | Установлен и авторизован    |

> **Примечание**: [Shizuku](https://shizuku.rikka.app/) требуется для расширенных функций управления разрешениями.
