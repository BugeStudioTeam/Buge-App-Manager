**Buge App Manager** é um utilitário poderoso para Android, concebido para a gestão avançada de aplicações e permissões. Construído com **Material Design 3 Expressive**, oferece uma interface moderna e intuitiva para um controlo detalhado do seu dispositivo.

## Funcionalidades

### Capacidades principais

| Funcionalidade                        | Descrição                                                                  |
| ------------------------------------- | -------------------------------------------------------------------------- |
| **Integração com Shizuku**            | Funciona com a autorização do Shizuku para controlo avançado sem root       |
| **Integração com Dhizuku**            | Funciona com a autorização de administrador de dispositivo do Dhizuku sem root |
| **Integração com ROOT**               | Funciona com a autorização de ROOT para controlo avançado                   |
| **Gestão de aplicações**              | Navegue e faça a gestão de aplicações do utilizador e do sistema            |
| **Interface Material Design 3 Expressive** | Interface limpa, com o tema do sistema, seguindo as diretrizes de design do Android |

### Gestor de aplicações

- Faça a gestão de qualquer aplicação, **incluindo aplicações do sistema**

- Suporta operações avançadas como **desinstalar**, **desativar**, **forçar paragem**, entre outras

- Permite **restaurar aplicações do sistema desinstaladas**

### Gestor de permissões

- Consulte e altere as permissões das aplicações por **categoria**
- Categorias suportadas: microfone, câmara, acesso à localização, notificações, telefone e contactos, armazenamento e outras
- Filtre permissões por estado **concedida** ou **negada**
- Operações de permissões em lote para várias aplicações

### Lançador de atividades

- Navegue e **inicie** qualquer atividade
- Consulte atividades não exportadas

### Privacidade e segurança

- Identifique rapidamente quais aplicações têm acesso a permissões sensíveis
- Otimize a segurança do dispositivo com informação clara sobre permissões

## Requisitos

| Requisito | Versão mínima                        |
| --------- | ------------------------------------ |
| Android   | 8.0 (API 26) ou superior             |
| Shizuku   | Instalado e autorizado               |
| Dhizuku   | Instalado e autorizado               |
| ROOT      | Dispositivo com root e autorizado    |

Escolha entre a autorização **Shizuku**, **Dhizuku** ou **ROOT**.

> **Nota**: é necessário [Shizuku](https://shizuku.rikka.app/) ou [Dhizuku](https://github.com/iamr0s/Dhizuku) para as funcionalidades avançadas de gestão de permissões.
