**Buge App Manager**는 앱과 권한을 고급 수준으로 관리하기 위해 설계된 강력한 Android 유틸리티입니다. **Material Design 3 Expressive**로 제작되었으며, 기기를 세밀하게 제어할 수 있는 현대적이고 직관적인 인터페이스를 제공합니다.

## 기능

### 핵심 기능

| 기능                                  | 설명                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------ |
| **Shizuku 연동**                      | Shizuku 권한으로 동작하여 루팅 없이 고급 제어 가능                        |
| **Dhizuku 연동**                      | Dhizuku 기기 관리자 권한으로 동작하여 루팅 없이 고급 제어 가능            |
| **ROOT 연동**                         | ROOT 권한으로 동작하여 고급 제어 가능                                      |
| **앱 관리**                           | 사용자 설치 앱과 시스템 앱을 모두 손쉽게 탐색하고 관리                     |
| **Material Design 3 Expressive UI**   | 최신 Android 디자인 가이드라인을 따르는 깔끔한 시스템 테마 인터페이스      |

### 앱 관리자

- **시스템 앱을 포함한** 모든 앱 관리

- **제거**, **비활성화**, **강제 중지** 등 고급 작업 지원

- **제거된 시스템 앱 복원** 지원

### 권한 관리자

- 앱 권한을 **카테고리**별로 확인하고 수정
- 지원 카테고리: 마이크, 카메라, 위치 액세스, 알림, 전화 및 연락처, 저장공간 등
- **허용됨** 또는 **거부됨** 상태로 권한 필터링
- 여러 앱에 대한 일괄 권한 작업

### 액티비티 런처

- 모든 액티비티를 탐색하고 **실행**
- 내보내지 않은 액티비티 확인

### 개인정보 및 보안

- 어떤 앱이 민감한 권한을 가지고 있는지 빠르게 확인
- 명확한 권한 정보로 기기의 보안 상태 최적화

## 요구 사항

| 요구 사항 | 최소 버전                  |
| --------- | -------------------------- |
| Android   | 8.0(API 26) 이상           |
| Shizuku   | 설치 및 권한 부여 완료     |
| Dhizuku   | 설치 및 권한 부여 완료     |
| ROOT      | 기기 루팅 및 권한 부여 완료 |

**Shizuku**, **Dhizuku**, **ROOT** 중 하나의 권한 부여 방식을 선택하세요.

> **참고**: 고급 권한 관리 기능에는 [Shizuku](https://shizuku.rikka.app/) 또는 [Dhizuku](https://github.com/iamr0s/Dhizuku)가 필요합니다.
