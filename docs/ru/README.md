**Buge App Manager** — мощная утилита для Android, предназначенная для продвинутого управления приложениями и разрешениями. Создана на **Material Design 3 Expressive** и предлагает современный и понятный интерфейс для тонкого контроля над устройством.

## Возможности

### Основные возможности

| Возможность                          | Описание                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------ |
| **Интеграция с Shizuku**             | Работает с авторизацией Shizuku для расширенного контроля без root        |
| **Интеграция с Dhizuku**             | Работает с авторизацией администратора устройства Dhizuku без root        |
| **Интеграция с ROOT**                | Работает с авторизацией ROOT для расширенного контроля                    |
| **Управление приложениями**          | Удобный просмотр и управление пользовательскими и системными приложениями |
| **Интерфейс Material Design 3 Expressive** | Чистый интерфейс в системной теме, следующий актуальным рекомендациям Android |

### Менеджер приложений

- Управление любыми приложениями, **включая системные**

- Поддержка расширенных операций: **удаление**, **отключение**, **принудительная остановка** и других

- **Восстановление удалённых системных приложений**

### Менеджер разрешений

- Просмотр и изменение разрешений приложений по **категориям**
- Поддерживаемые категории: микрофон, камера, доступ к местоположению, уведомления, телефон и контакты, хранилище и другие
- Фильтрация разрешений по статусу **предоставлено** или **отклонено**
- Пакетные операции с разрешениями для нескольких приложений

### Запуск Activity

- Просмотр и **запуск** любой Activity
- Просмотр неэкспортированных Activity

### Конфиденциальность и безопасность

- Быстрое определение приложений с доступом к чувствительным разрешениям
- Оптимизация безопасности устройства благодаря наглядной информации о разрешениях

## Требования

| Требование | Минимальная версия                    |
| ---------- | ------------------------------------- |
| Android    | 8.0 (API 26) или выше                 |
| Shizuku    | Установлен и авторизован              |
| Dhizuku    | Установлен и авторизован              |
| ROOT       | Устройство рутировано и авторизовано  |

Выберите один из вариантов авторизации: **Shizuku**, **Dhizuku** или **ROOT**.

> **Примечание**: для расширенного управления разрешениями требуется [Shizuku](https://shizuku.rikka.app/) или [Dhizuku](https://github.com/iamr0s/Dhizuku).
