## ✨ Recursos

### 🚀 Capacidades principais

| Recurso                              | Descrição                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| **Integração com Shizuku**           | Opera com autorização Shizuku para controle avançado sem necessidade de root       |
| **Gerenciamento de aplicativos**     | Navegue e gerencie facilmente aplicativos instalados pelo usuário e aplicativos de sistema |
| **Interface Material Design 3 Expressive** | Interface limpa e temática que segue as mais recentes diretrizes de design do Android |

### 📱 Gerenciador de aplicativos

- Gerencie qualquer aplicativo, **incluindo aplicativos de sistema**

- Permite operações avançadas como **desinstalar**, **desativar**, **forçar parada**, etc.

- Permite **restaurar aplicativos de sistema desinstalados**

### 🔐 Gerenciador de permissões

- Visualize e modifique permissões de aplicativos por categoria
- Categorias suportadas: Microfone, Câmera, Acesso à localização, Notificações, Telefone e Contatos, Armazenamento e Outras
- Filtre permissões por status **concedido** ou **negado**
- Operações em lote de permissões para vários aplicativos

### 🧩 Lançador de Activities

- Navegue e **inicie** qualquer Activity
- Visualize Activities não exportadas

### 🛡️ Privacidade e segurança

- Identifique rapidamente quais aplicativos têm acesso a permissões sensíveis
- Otimize a postura de segurança do seu dispositivo com informações claras sobre permissões

## 📋 Requisitos

| Requisito   | Versão mínima             |
| ----------- | ------------------------- |
| Android OS  | 8.0 (API 26) ou superior  |
| Shizuku     | Instalado e autorizado    |

> **Nota**: O [Shizuku](https://shizuku.rikka.app/) é necessário para recursos avançados de gerenciamento de permissões.
