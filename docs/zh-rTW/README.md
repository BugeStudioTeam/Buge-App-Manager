**Buge App Manager** 是一款功能強大的 Android 實用工具，專為進階應用程式與權限管理而設計。它以 **Material Design 3 Expressive** 打造，提供現代且直覺的介面，讓你精細掌控自己的裝置。

## 功能特色

### 核心能力

| 功能                                  | 說明                                                                        |
| ------------------------------------- | --------------------------------------------------------------------------- |
| **Shizuku 整合**                      | 透過 Shizuku 授權運作，無需 Root 即可取得進階控制權                          |
| **Dhizuku 整合**                      | 透過 Dhizuku 裝置管理員授權運作，無需 Root 即可取得進階控制權                |
| **ROOT 整合**                         | 透過 ROOT 授權運作，取得進階控制權                                           |
| **應用程式管理**                      | 輕鬆瀏覽並管理使用者安裝的應用程式與系統應用程式                             |
| **Material Design 3 Expressive 介面** | 乾淨、跟隨系統主題的介面，遵循最新的 Android 設計規範                        |

### 應用程式管理器

- 管理任何應用程式，**包括系統應用程式**

- 支援**解除安裝**、**停用**、**強制停止**等進階操作

- 支援**還原已解除安裝的系統應用程式**

### 權限管理器

- 依**類別**檢視與修改應用程式權限
- 支援的類別包括：麥克風、相機、位置存取、通知、電話與聯絡人、儲存空間等
- 依**已授予**或**已拒絕**狀態篩選權限
- 支援對多個應用程式批次操作權限

### Activity 啟動器

- 瀏覽並**啟動**任何 Activity
- 檢視未匯出的 Activity

### 隱私與安全

- 快速找出哪些應用程式擁有敏感權限
- 透過清楚的權限洞察最佳化裝置的安全狀態

## 系統需求

| 需求     | 最低版本                       |
| -------- | ------------------------------ |
| Android  | 8.0（API 26）或更新版本        |
| Shizuku  | 已安裝並已授權                 |
| Dhizuku  | 已安裝並已授權                 |
| ROOT     | 裝置已 Root 並已授權           |

可在 **Shizuku**、**Dhizuku** 或 **ROOT** 授權方式中擇一使用。

> **注意**：進階權限管理功能需要 [Shizuku](https://shizuku.rikka.app/) 或 [Dhizuku](https://github.com/iamr0s/Dhizuku)。
