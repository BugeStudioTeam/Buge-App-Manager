## ✨ 功能特性

### 🚀 核心能力

| 功能                             | 描述                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| **Shizuku 集成**             | 通过 Shizuku 授权运行，无需 Root 即可获得高级控制权限                         |
| **应用管理**                  | 轻松浏览和管理用户安装的应用及系统应用                                        |
| **Material Design 3 Expressive 界面** | 干净、系统主题风格的界面，遵循最新的 Android 设计规范                      |

### 📱 应用管理器

- 管理任何应用，**包括系统应用**

- 支持高级操作，如**卸载**、**禁用**、**强制停止**等

- 支持**恢复已卸载的系统应用**

### 🔐 权限管理器

- 按类别查看和修改应用权限
- 支持的类别包括：麦克风、相机、位置访问、通知、电话与联系人、存储和其他
- 按**已授予**或**已拒绝**状态筛选权限
- 支持对多个应用进行批量权限操作

### 🧩 Activity 启动器

- 浏览并**启动**任意 Activity
- 可查看未导出的 Activity

### 🛡️ 隐私与安全

- 快速识别哪些应用拥有敏感权限
- 通过清晰的权限洞察优化设备安全状态

## 📋 系统要求

| 要求         | 最低版本                |
| ------------ | ----------------------- |
| Android 系统 | 8.0 (API 26) 或更高版本 |
| Shizuku      | 已安装并已授权          |

> **注意**：高级权限管理功能需要 [Shizuku](https://shizuku.rikka.app/) 支持。
