## ✨ 기능

### 🚀 핵심 기능

| 기능                                | 설명                                                                               |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| **Shizuku 통합**                    | Shizuku 권한 부여로 작동하며 루트 없이도 고급 제어 가능                            |
| **앱 관리**                         | 사용자 설치 앱과 시스템 앱을 모두 쉽게 탐색하고 관리                               |
| **Material Design 3 Expressive UI** | 최신 Android 디자인 가이드라인을 따르는 깔끔한 시스템 테마 인터페이스              |

### 📱 앱 매니저

- **시스템 앱을 포함한** 모든 앱 관리

- **제거**, **비활성화**, **강제 중지** 등의 고급 작업 지원

- **제거된 시스템 앱 복원** 지원

### 🔐 권한 매니저

- 카테고리별로 앱 권한 확인 및 수정
- 지원 카테고리: 마이크, 카메라, 위치 접근, 알림, 전화 및 연락처, 저장소, 기타
- **허용됨** 또는 **거부됨** 상태로 권한 필터링
- 여러 앱에 대한 일괄 권한 작업

### 🧩 Activity 실행기

- 모든 Activity 탐색 및 **실행**
- 내보내지지 않은 Activity도 표시

### 🛡️ 프라이버시 및 보안

- 민감한 권한에 접근할 수 있는 앱을 신속하게 식별
- 명확한 권한 인사이트로 장치 보안 상태 최적화

## 📋 요구 사항

| 요구 사항  | 최소 버전                |
| ---------- | ------------------------ |
| Android OS | 8.0 (API 26) 이상        |
| Shizuku    | 설치 및 권한 부여 완료   |

> **참고**: 고급 권한 관리 기능을 사용하려면 [Shizuku](https://shizuku.rikka.app/)가 필요합니다.
