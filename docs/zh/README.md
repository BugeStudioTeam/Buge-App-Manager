**Buge App Manager** 是一款功能强大的 Android 实用工具，专为高级应用与权限管理而设计。它基于 **Material Design 3 Expressive** 构建，提供现代、直观的界面，让你可以精细控制自己的设备。

## 功能特性

### 核心能力

| 功能                                 | 说明                                                                          |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| **Shizuku 集成**                     | 通过 Shizuku 授权运行，无需 Root 即可获得高级控制能力                          |
| **Dhizuku 集成**                     | 通过 Dhizuku 设备管理员授权运行，无需 Root 即可获得高级控制能力                |
| **ROOT 集成**                        | 通过 ROOT 授权运行，获得高级控制能力                                           |
| **应用管理**                         | 轻松浏览并管理用户安装的应用和系统应用                                         |
| **Material Design 3 Expressive 界面** | 干净、跟随系统主题的界面，遵循最新的 Android 设计规范                          |

### 应用管理器

- 管理任意应用，**包括系统应用**

- 支持**卸载**、**禁用**、**强制停止**等高级操作

- 支持**恢复已卸载的系统应用**

### 权限管理器

- 按**类别**查看和修改应用权限
- 支持的类别包括：麦克风、相机、位置信息、通知、电话与联系人、存储等
- 按**已授予**或**已拒绝**状态筛选权限
- 支持对多个应用批量操作权限

### Activity 启动器

- 浏览并**启动**任意 Activity
- 查看未导出的 Activity

### 隐私与安全

- 快速找出哪些应用拥有敏感权限
- 通过清晰的权限洞察优化设备的安全状态

## 系统要求

| 要求     | 最低版本                       |
| -------- | ------------------------------ |
| Android  | 8.0（API 26）或更高            |
| Shizuku  | 已安装并已授权                 |
| Dhizuku  | 已安装并已授权                 |
| ROOT     | 设备已 Root 并已授权           |

可在 **Shizuku**、**Dhizuku** 或 **ROOT** 授权方式中选择一种。

> **注意**：高级权限管理功能需要 [Shizuku](https://shizuku.rikka.app/) 或 [Dhizuku](https://github.com/iamr0s/Dhizuku)。
