# Contributing Guide

Thanks for your interest in contributing. Please read the rules below before submitting.

## Branch

All changes must be submitted to the `develop` branch.

```bash
git checkout develop
git pull origin develop
git checkout -b feature/your-feature-name
```bash

When done, open a Pull Request against `develop`.

## Prohibited

- Malicious code (viruses, trojans, backdoors, miners, etc.)
- Stealing or uploading user privacy
- Forced ads, bundling, or hidden paywalls
- Modifying user system settings without consent
- Infringing content
- Anything violating laws or GitHub's Terms of Service

## Before Submitting

- [ ] Target branch is `develop`
- [ ] Code runs without errors
- [ ] No malicious or hidden behavior
- [ ] Clear commit message

## Commit Message

```bash
type: short description
```bash

Types: `feat` / `fix` / `docs` / `refactor` / `perf` / `test` / `chore`

## Pull Request

1. Create a branch from `develop`
2. Commit and push
3. Open a PR against `develop`
4. Wait for review and apply feedback

PRs that violate these rules will be closed without notice. Repeat offenders will be banned.
