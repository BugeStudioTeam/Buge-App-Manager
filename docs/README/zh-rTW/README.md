**Buge App Manager** 是一款功能強大的 Android 實用工具應用程式，專為進階應用程式和權限管理而設計。它基於 **Material Design 3 Expressive** 建構，提供現代化且直觀的介面，讓您對裝置進行精細控制。

## ✨ 功能特性

### 🚀 核心能力

| 功能                             | 描述                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| **Shizuku 整合**             | 透過 Shizuku 授權執行，無需 Root 即可獲得進階控制權限                         |
| **應用程式管理**                  | 輕鬆瀏覽和管理使用者安裝的應用程式及系統應用程式                              |
| **Material Design 3 Expressive 介面** | 乾淨、系統主題風格的介面，遵循最新的 Android 設計規範                      |

### 📱 應用程式管理器

- 管理任何應用程式，**包括系統應用程式**

- 支援進階操作，如**解除安裝**、**停用**、**強制停止**等

- 支援**還原已解除安裝的系統應用程式**

### 🔐 權限管理器

- 按類別檢視和修改應用程式權限
- 支援的類別包括：麥克風、相機、位置存取、通知、電話與聯絡人、儲存空間和其他
- 按**已授予**或**已拒絕**狀態篩選權限
- 支援對多個應用程式進行批次權限操作

### 🧩 Activity 啟動器

- 瀏覽並**啟動**任意 Activity
- 可檢視未匯出的 Activity

### 🛡️ 隱私與安全

- 快速識別哪些應用程式擁有敏感權限
- 透過清晰的權限洞察最佳化裝置安全狀態

## 📋 系統要求

| 要求         | 最低版本                |
| ------------ | ----------------------- |
| Android 系統 | 8.0 (API 26) 或更高版本 |
| Shizuku      | 已安裝並已授權          |

> **注意**：進階權限管理功能需要 [Shizuku](https://shizuku.rikka.app/) 支援。
