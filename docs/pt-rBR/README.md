**Buge App Manager** é um utilitário poderoso para Android, criado para o gerenciamento avançado de aplicativos e permissões. Construído com **Material Design 3 Expressive**, oferece uma interface moderna e intuitiva para um controle detalhado do seu dispositivo.

## Recursos

### Capacidades principais

| Recurso                               | Descrição                                                                  |
| ------------------------------------- | -------------------------------------------------------------------------- |
| **Integração com Shizuku**            | Funciona com a autorização do Shizuku para controle avançado sem root       |
| **Integração com Dhizuku**            | Funciona com a autorização de administrador de dispositivo do Dhizuku sem root |
| **Integração com ROOT**               | Funciona com a autorização de ROOT para controle avançado                   |
| **Gerenciamento de aplicativos**      | Navegue e gerencie aplicativos do usuário e do sistema com facilidade       |
| **Interface Material Design 3 Expressive** | Interface limpa, com o tema do sistema, seguindo as diretrizes de design do Android |

### Gerenciador de aplicativos

- Gerencie qualquer aplicativo, **incluindo aplicativos do sistema**

- Suporta operações avançadas como **desinstalar**, **desativar**, **forçar parada** e outras

- Permite **restaurar aplicativos do sistema desinstalados**

### Gerenciador de permissões

- Visualize e altere as permissões dos aplicativos por **categoria**
- Categorias compatíveis: microfone, câmera, acesso à localização, notificações, telefone e contatos, armazenamento e outras
- Filtre permissões por status **concedida** ou **negada**
- Operações de permissões em lote para vários aplicativos

### Iniciador de atividades

- Navegue e **inicie** qualquer atividade
- Visualize atividades não exportadas

### Privacidade e segurança

- Identifique rapidamente quais aplicativos têm acesso a permissões sensíveis
- Otimize a segurança do dispositivo com informações claras sobre permissões

## Requisitos

| Requisito | Versão mínima                        |
| --------- | ------------------------------------ |
| Android   | 8.0 (API 26) ou superior             |
| Shizuku   | Instalado e autorizado               |
| Dhizuku   | Instalado e autorizado               |
| ROOT      | Dispositivo com root e autorizado    |

Escolha entre a autorização **Shizuku**, **Dhizuku** ou **ROOT**.

> **Observação**: é necessário [Shizuku](https://shizuku.rikka.app/) ou [Dhizuku](https://github.com/iamr0s/Dhizuku) para os recursos avançados de gerenciamento de permissões.
