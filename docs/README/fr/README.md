## ✨ Fonctionnalités

### 🚀 Capacités principales

| Fonctionnalité                       | Description                                                                        |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| **Intégration Shizuku**              | Fonctionne avec l'autorisation Shizuku pour un contrôle avancé sans nécessiter de root |
| **Gestion des applications**         | Parcourez et gérez facilement les applications installées par l'utilisateur et les applications système |
| **Interface Material Design 3 Expressive** | Interface épurée et thématique qui suit les dernières directives de conception Android |

### 📱 Gestionnaire d'applications

- Gérez n'importe quelle application, **y compris les applications système**

- Permet des opérations avancées telles que **désinstaller**, **désactiver**, **forcer l'arrêt**, etc.

- Permet de **restaurer les applications système désinstallées**

### 🔐 Gestionnaire d'autorisations

- Affichez et modifiez les autorisations des applications par catégorie
- Catégories prises en charge : Microphone, Caméra, Accès à la localisation, Notifications, Téléphone et Contacts, Stockage et Autres
- Filtrez les autorisations par statut **accordé** ou **refusé**
- Opérations par lot sur les autorisations pour plusieurs applications

### 🧩 Lanceur d'activités

- Parcourez et **lancez** n'importe quelle activité
- Affichez les activités non exportées

### 🛡️ Vie privée et sécurité

- Identifiez rapidement les applications qui ont accès à des autorisations sensibles
- Optimisez la posture de sécurité de votre appareil grâce à des informations claires sur les autorisations

## 📋 Prérequis

| Prérequis   | Version minimale           |
| ----------- | -------------------------- |
| Android OS  | 8.0 (API 26) ou supérieure |
| Shizuku     | Installé et autorisé       |

> **Remarque** : [Shizuku](https://shizuku.rikka.app/) est requis pour les fonctionnalités avancées de gestion des autorisations.
