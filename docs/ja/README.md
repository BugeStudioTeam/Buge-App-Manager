## ✨ 機能

### 🚀 コア機能

| 機能                                | 説明                                                                                |
| ----------------------------------- | ----------------------------------------------------------------------------------- |
| **Shizuku 統合**                    | Shizuku 認証で動作し、root を必要とせずに高度な制御を実現                           |
| **アプリ管理**                      | ユーザーインストールアプリとシステムアプリの両方を簡単に参照・管理                    |
| **Material Design 3 Expressive UI** | 最新の Android デザインガイドラインに従った、クリーンでシステムテーマのインターフェース |

### 📱 アプリマネージャー

- **システムアプリを含む**、あらゆるアプリを管理

- **アンインストール**、**無効化**、**強制停止**などの高度な操作が可能

- **アンインストールしたシステムアプリの復元**が可能

### 🔐 権限マネージャー

- カテゴリ別にアプリの権限を表示・変更
- 対応カテゴリ：マイク、カメラ、位置情報アクセス、通知、電話と連絡先、ストレージ、その他
- 権限を**付与**または**拒否**のステータスでフィルタリング
- 複数アプリに対するバッチ権限操作

### 🧩 Activity ランチャー

- 任意の Activity を参照して**起動**
- エクスポートされていない Activity も表示

### 🛡️ プライバシーとセキュリティ

- どのアプリが機密性の高い権限にアクセスできるかをすばやく特定
- 明確な権限インサイトでデバイスのセキュリティ態勢を最適化

## 📋 要件

| 要件       | 最小バージョン             |
| ---------- | -------------------------- |
| Android OS | 8.0 (API 26) 以上          |
| Shizuku    | インストールおよび認証済み |

> **注意**: 高度な権限管理機能には [Shizuku](https://shizuku.rikka.app/) が必要です。
