**Buge App Manager** ist eine leistungsstarke Android-Dienstprogramm-App, die für erweiterte App- und Berechtigungsverwaltung entwickelt wurde. Entwickelt mit **Material Design 3 Expressive** bietet sie eine moderne und intuitive Oberfläche für granulare Kontrolle über Ihr Gerät.

## ✨ Funktionen

### 🚀 Kernfunktionen

| Funktion                             | Beschreibung                                                                        |
| ------------------------------------ | ----------------------------------------------------------------------------------- |
| **Shizuku-Integration**              | Arbeitet mit Shizuku-Autorisierung für erweiterte Kontrolle ohne Root-Zugriff       |
| **App-Verwaltung**                   | Durchsuchen und verwalten Sie sowohl benutzerinstallierte als auch System-Apps einfach |
| **Material Design 3 Expressive-Oberfläche** | Saubere, systemthematische Oberfläche nach den neuesten Android-Designrichtlinien |

### 📱 App-Manager

- Verwalten Sie jede App, **einschließlich System-Apps**

- Ermöglicht erweiterte Operationen wie **Deinstallieren**, **Deaktivieren**, **Erzwingen des Beendens**, usw.

- Ermöglicht das **Wiederherstellen deinstallierter System-Apps**

### 🔐 Berechtigungsmanager

- Zeigen Sie App-Berechtigungen nach Kategorie an und ändern Sie sie
- Unterstützte Kategorien: Mikrofon, Kamera, Standortzugriff, Benachrichtigungen, Telefon & Kontakte, Speicher und Sonstige
- Filtern Sie Berechtigungen nach Status **gewährt** oder **verweigert**
- Stapelverarbeitung von Berechtigungen für mehrere Apps

### 🧩 Activity-Startprogramm

- Durchsuchen und **starten** Sie jede Activity
- Zeigen Sie nicht exportierte Activities an

### 🛡️ Datenschutz & Sicherheit

- Identifizieren Sie schnell, welche Apps Zugriff auf sensible Berechtigungen haben
- Optimieren Sie die Sicherheitslage Ihres Geräts mit klaren Berechtigungseinblicken

## 📋 Voraussetzungen

| Voraussetzung | Mindestversion            |
| ------------- | ------------------------- |
| Android OS    | 8.0 (API 26) oder höher   |
| Shizuku       | Installiert und autorisiert |

> **Hinweis**: [Shizuku](https://shizuku.rikka.app/) ist für erweiterte Berechtigungsverwaltungsfunktionen erforderlich.
