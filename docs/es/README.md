## ✨ Características

### 🚀 Capacidades principales

| Característica                       | Descripción                                                                        |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| **Integración con Shizuku**          | Funciona con autorización de Shizuku para control avanzado sin necesidad de root   |
| **Gestión de aplicaciones**          | Navegue y gestione fácilmente aplicaciones instaladas por el usuario y aplicaciones del sistema |
| **Interfaz Material Design 3 Expressive** | Interfaz limpia y temática que sigue las últimas directrices de diseño de Android |

### 📱 Gestor de aplicaciones

- Gestione cualquier aplicación, **incluidas las aplicaciones del sistema**

- Permite operaciones avanzadas como **desinstalar**, **deshabilitar**, **forzar detención**, etc.

- Permite **restaurar aplicaciones del sistema desinstaladas**

### 🔐 Gestor de permisos

- Vea y modifique los permisos de las aplicaciones por categoría
- Categorías compatibles: Micrófono, Cámara, Acceso a la ubicación, Notificaciones, Teléfono y Contactos, Almacenamiento y Otras
- Filtre los permisos por estado **concedido** o **denegado**
- Operaciones por lotes de permisos para múltiples aplicaciones

### 🧩 Lanzador de Activities

- Navegue y **lance** cualquier Activity
- Vea Activities no exportadas

### 🛡️ Privacidad y seguridad

- Identifique rápidamente qué aplicaciones tienen acceso a permisos sensibles
- Optimice la postura de seguridad de su dispositivo con información clara sobre los permisos

## 📋 Requisitos

| Requisito   | Versión mínima            |
| ----------- | ------------------------- |
| Android OS  | 8.0 (API 26) o superior   |
| Shizuku     | Instalado y autorizado    |

> **Nota**: [Shizuku](https://shizuku.rikka.app/) es necesario para las funciones avanzadas de gestión de permisos.
