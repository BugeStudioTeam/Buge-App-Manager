**Buge App Manager** は、アプリと権限の高度な管理に特化した強力な Android ユーティリティです。**Material Design 3 Expressive** で構築されており、端末をきめ細かく制御できるモダンで直感的なインターフェースを提供します。

## 機能

### コア機能

| 機能                                  | 説明                                                                        |
| ------------------------------------- | --------------------------------------------------------------------------- |
| **Shizuku 連携**                      | Shizuku の認可で動作し、root 化なしで高度な制御が可能                        |
| **Dhizuku 連携**                      | Dhizuku のデバイス管理者認可で動作し、root 化なしで高度な制御が可能          |
| **ROOT 連携**                         | ROOT の認可で動作し、高度な制御が可能                                        |
| **アプリ管理**                        | ユーザーがインストールしたアプリとシステムアプリの両方を簡単に管理           |
| **Material Design 3 Expressive UI**   | 最新の Android デザインガイドラインに沿った、システムテーマ対応のクリーンな UI |

### アプリマネージャー

- **システムアプリを含む**あらゆるアプリを管理

- **アンインストール**、**無効化**、**強制停止**などの高度な操作に対応

- **アンインストールしたシステムアプリの復元**に対応

### 権限マネージャー

- アプリの権限を**カテゴリ**ごとに表示・変更
- 対応カテゴリ：マイク、カメラ、位置情報、通知、電話と連絡先、ストレージなど
- **許可済み**または**拒否済み**の状態で権限を絞り込み
- 複数のアプリに対して権限を一括操作

### アクティビティランチャー

- あらゆるアクティビティを閲覧して**起動**
- エクスポートされていないアクティビティも表示

### プライバシーとセキュリティ

- どのアプリが機密性の高い権限を持っているかをすばやく確認
- 明確な権限の可視化で端末のセキュリティ状態を最適化

## 動作要件

| 要件     | 最低バージョン                 |
| -------- | ------------------------------ |
| Android  | 8.0（API 26）以降              |
| Shizuku  | インストール済みかつ認可済み   |
| Dhizuku  | インストール済みかつ認可済み   |
| ROOT     | 端末が root 化済みかつ認可済み |

**Shizuku**、**Dhizuku**、**ROOT** のいずれかの認可を選択してください。

> **注記**：高度な権限管理機能には [Shizuku](https://shizuku.rikka.app/) または [Dhizuku](https://github.com/iamr0s/Dhizuku) が必要です。
