## Fonctionnalités

### Capacités principales

| Fonctionnalité                        | Description                                                                |
| ------------------------------------- | -------------------------------------------------------------------------- |
| **Intégration Shizuku**               | Fonctionne avec l'autorisation Shizuku pour un contrôle avancé sans root    |
| **Intégration Dhizuku**               | Fonctionne avec l'autorisation administrateur d'appareil Dhizuku sans root  |
| **Intégration ROOT**                  | Fonctionne avec l'autorisation ROOT pour un contrôle avancé                 |
| **Gestion des applications**          | Parcourez et gérez facilement les applications utilisateur et système       |
| **Interface Material Design 3 Expressive** | Interface épurée au thème système, conforme aux dernières recommandations Android |

### Gestionnaire d'applications

- Gérez n'importe quelle application, **y compris les applications système**

- Prend en charge les opérations avancées comme **désinstaller**, **désactiver**, **forcer l'arrêt**, etc.

- Possibilité de **restaurer les applications système désinstallées**

### Gestionnaire de permissions

- Affichez et modifiez les permissions des applications par **catégorie**
- Catégories prises en charge : microphone, caméra, accès à la localisation, notifications, téléphone et contacts, stockage et autres
- Filtrez les permissions par statut **accordée** ou **refusée**
- Opérations par lots sur les permissions de plusieurs applications

### Lanceur d'activités

- Parcourez et **lancez** n'importe quelle activité
- Affichez les activités non exportées

### Confidentialité et sécurité

- Identifiez rapidement les applications ayant accès à des permissions sensibles
- Optimisez la sécurité de votre appareil grâce à une vision claire des permissions

## Configuration requise

| Prérequis | Version minimale                        |
| --------- | --------------------------------------- |
| Android   | 8.0 (API 26) ou supérieur               |
| Shizuku   | Installé et autorisé                    |
| Dhizuku   | Installé et autorisé                    |
| ROOT      | Appareil rooté et autorisé              |

Choisissez entre l'autorisation **Shizuku**, **Dhizuku** ou **ROOT**.

> **Remarque** : [Shizuku](https://shizuku.rikka.app/) ou [Dhizuku](https://github.com/iamr0s/Dhizuku) est requis pour les fonctions avancées de gestion des permissions.
