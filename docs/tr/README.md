## Özellikler

### Temel yetenekler

| Özellik                               | Açıklama                                                                 |
| ------------------------------------- | ------------------------------------------------------------------------ |
| **Shizuku entegrasyonu**              | Root gerektirmeden gelişmiş kontrol için Shizuku yetkilendirmesiyle çalışır |
| **Dhizuku entegrasyonu**              | Root gerektirmeden gelişmiş kontrol için Dhizuku cihaz yöneticisi yetkilendirmesiyle çalışır |
| **ROOT entegrasyonu**                 | Gelişmiş kontrol için ROOT yetkilendirmesiyle çalışır                     |
| **Uygulama yönetimi**                 | Kullanıcı uygulamalarını ve sistem uygulamalarını kolayca yönetin          |
| **Material Design 3 Expressive arayüz** | En güncel Android tasarım yönergelerini izleyen temiz, sistem temalı arayüz |

### Uygulama Yöneticisi

- **Sistem uygulamaları dahil** tüm uygulamaları yönetin

- **Kaldırma**, **devre dışı bırakma**, **zorla durdurma** gibi gelişmiş işlemleri destekler

- **Kaldırılan sistem uygulamalarını geri yükleme** desteği

### İzin Yöneticisi

- Uygulama izinlerini **kategoriye** göre görüntüleyin ve değiştirin
- Desteklenen kategoriler: Mikrofon, Kamera, Konum erişimi, Bildirimler, Telefon ve Kişiler, Depolama ve diğerleri
- İzinleri **verildi** veya **reddedildi** durumuna göre filtreleyin
- Birden fazla uygulama için toplu izin işlemleri

### Etkinlik Başlatıcı

- Herhangi bir etkinliği görüntüleyin ve **başlatın**
- Dışa aktarılmamış etkinlikleri görüntüleyin

### Gizlilik ve Güvenlik

- Hangi uygulamaların hassas izinlere erişimi olduğunu hızla belirleyin
- Net izin bilgileriyle cihazınızın güvenlik durumunu iyileştirin

## Gereksinimler

| Gereksinim | Minimum sürüm                        |
| ---------- | ------------------------------------ |
| Android    | 8.0 (API 26) veya üzeri              |
| Shizuku    | Kurulu ve yetkilendirilmiş           |
| Dhizuku    | Kurulu ve yetkilendirilmiş           |
| ROOT       | Cihaz rootlanmış ve yetkilendirilmiş |

**Shizuku**, **Dhizuku** veya **ROOT** yetkilendirmelerinden birini seçin.

> **Not**: Gelişmiş izin yönetimi özellikleri için [Shizuku](https://shizuku.rikka.app/) veya [Dhizuku](https://github.com/iamr0s/Dhizuku) gereklidir.
