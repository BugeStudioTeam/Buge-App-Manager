**Buge App Manager** ist ein leistungsstarkes Android-Werkzeug für fortgeschrittene App- und Berechtigungsverwaltung. Entwickelt mit **Material Design 3 Expressive** bietet es eine moderne, intuitive Oberfläche für die feingranulare Kontrolle über dein Gerät.

## Funktionen

### Kernfunktionen

| Funktion                              | Beschreibung                                                             |
| ------------------------------------- | ------------------------------------------------------------------------ |
| **Shizuku-Integration**               | Arbeitet mit Shizuku-Autorisierung für erweiterte Kontrolle ohne Root     |
| **Dhizuku-Integration**               | Arbeitet mit Dhizuku-Geräteadministrator-Autorisierung ohne Root          |
| **ROOT-Integration**                  | Arbeitet mit ROOT-Autorisierung für erweiterte Kontrolle                  |
| **App-Verwaltung**                    | Benutzer- und System-Apps bequem durchsuchen und verwalten                |
| **Material Design 3 Expressive UI**   | Klare, systemthemenkonforme Oberfläche nach aktuellen Android-Richtlinien |

### App-Manager

- Verwaltung beliebiger Apps, **auch System-Apps**

- Unterstützung erweiterter Aktionen wie **Deinstallieren**, **Deaktivieren**, **Stoppen erzwingen** usw.

- **Wiederherstellen deinstallierter System-Apps**

### Berechtigungsmanager

- App-Berechtigungen nach **Kategorie** anzeigen und ändern
- Unterstützte Kategorien: Mikrofon, Kamera, Standortzugriff, Benachrichtigungen, Telefon & Kontakte, Speicher und weitere
- Berechtigungen nach Status **erteilt** oder **verweigert** filtern
- Stapelverarbeitung von Berechtigungen für mehrere Apps

### Activity-Launcher

- Beliebige Activities durchsuchen und **starten**
- Nicht exportierte Activities anzeigen

### Datenschutz & Sicherheit

- Schnell erkennen, welche Apps Zugriff auf sensible Berechtigungen haben
- Die Sicherheit deines Geräts durch klare Berechtigungseinblicke verbessern

## Voraussetzungen

| Voraussetzung | Mindestversion                       |
| ------------- | ------------------------------------ |
| Android       | 8.0 (API 26) oder höher              |
| Shizuku       | Installiert und autorisiert          |
| Dhizuku       | Installiert und autorisiert          |
| ROOT          | Gerät gerootet und autorisiert       |

Wähle zwischen **Shizuku**, **Dhizuku** oder **ROOT** als Autorisierung.

> **Hinweis**: Für erweiterte Berechtigungsverwaltung ist [Shizuku](https://shizuku.rikka.app/) oder [Dhizuku](https://github.com/iamr0s/Dhizuku) erforderlich.
